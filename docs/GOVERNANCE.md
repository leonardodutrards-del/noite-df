# Governança de desenvolvimento

Fluxo obrigatório:

1. diagnóstico;
2. plano;
3. aprovação;
4. implementação pequena;
5. testes;
6. revisão;
7. deploy controlado;
8. validação humana;
9. aprendizados.

## Regras
- Preservar comportamentos existentes antes de substituir componentes.
- Separar dados de demonstração dos dados operacionais.
- Não publicar conteúdo externo sem fonte e data de verificação.
- Alterações sensíveis de parceiros devem permitir revisão administrativa.
- Toda mudança de regra de negócio deve ser documentada.
- Conteúdo patrocinado deve ser explicitamente identificado.
